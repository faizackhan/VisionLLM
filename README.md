# Vision: a UTSC course and program advisor

Ask about any UTSC course or program in plain language ("what do I need before CSCB07?", "what programs does Psychology offer?") and get an answer grounded in the public UTSC Academic Calendar. Everything runs locally with Ollama and Chroma, so your questions never leave your computer.

> Unofficial student project, not affiliated with the University of Toronto. Answers are generated by a small language model, so always confirm important decisions against the official calendar or an academic advisor.

![Vision screenshot](VisionLLM/visionss.png)

## Features

- **Covers the whole calendar.** A scraper collects every course and program from the UTSC calendar's discipline pages, so it isn't limited to one department.
- **Hybrid retrieval.** Course codes (and shorthand like `b07` or `csca48`) trigger exact lookups in a prerequisite graph, while everything else goes through vector search over courses, programs and policies.
- **Self-checking answers.** A grader model filters out irrelevant search results, retries once with a rewritten query, and flags answers the sources don't support.
- **Exact calendar wording, always.** Small local models can garble "and" / "or" in prerequisites, so the original calendar text is shown under every answer with a link to the source page.
- **Chat history.** Past chats are listed in the sidebar and saved locally.

## How it works

```
UTSC calendar ──► scrape.py ──► courses.json + programs.json
                                        │
                                        ▼
                                    build.py ──► Chroma index (courses, programs/policies)
                                        │         + prerequisite graph (NetworkX)
                                        ▼
question ──► rag.py ──► course codes? ──► graph facts (exact prerequisites)
                    └─► vector search ──► grader filters chunks ──► answer ──► grounding check
                                                                       │
                                            exact calendar wording ◄───┘
```

1. **Scrape** (`advisor/scrape.py`): downloads the Program Sections A to Z pages. Each discipline page holds that department's courses and programs, which are parsed into structured records (code, title, description, prerequisites, exclusions, breadth) and chunked program text.
2. **Index** (`advisor/build.py`, `advisor/index.py`): embeds everything with `nomic-embed-text` and stores it in two Chroma collections, `courses` and `policies` (program requirements and academic regulations).
3. **Graph** (`advisor/graph.py`): course prerequisites become a directed graph, so questions like "what does this course lead to?" are exact lookups, not guesses.
4. **Answer** (`advisor/rag.py`): retrieves, grades, generates with `llama3.2`, then checks that the answer is supported by what was retrieved.
5. **UI** (`app.py`): a Streamlit app styled after the Vision design.

## Setup

Requires [Ollama](https://ollama.com) and Python (developed with 3.12).

```bash
git clone https://github.com/faizackhan/VisionLLM.git
cd VisionLLM
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

ollama pull llama3.2
ollama pull nomic-embed-text

python -m advisor.scrape     # downloads the calendar (a few minutes)
python -m advisor.build      # builds the search index (a few minutes)
python -m streamlit run app.py
```

Make sure the Ollama app is running before you start.

**Useful scraper options**

| Command | What it does |
| --- | --- |
| `python -m advisor.scrape --only Statistics` | Test on one discipline; writes `*_test.json` files and leaves your real data alone |
| `python -m advisor.scrape --fresh` | Ignore the cache and download everything again |

The **Refresh** button in the app runs a fresh scrape and rebuild. Restart the app afterwards to load the new data.

## Data and privacy

- All models run locally through Ollama, and the vector index is stored on your machine.
- The calendar content belongs to the University of Toronto, so the scraped data is **not** included in this repo. The scraper is throttled to one request per second and caches every page, so a normal run downloads each page once.
- Chat history is saved to `advisor/data/private/chats.json` on your machine only, and is excluded from git.

## Limitations

- A small local model can misread complicated prerequisites (nested "and" / "or", grade or program-enrolment conditions). About a fifth of courses are flagged as complicated during scraping. Use the calendar wording shown under each answer.
- Shorthand like `b07` can match courses in several departments, in which case Vision lists the candidates.
- The data is a snapshot from the last scrape or Refresh, so new or changed courses appear only after refreshing.
- Program requirements are long free text, so answers about them depend on retrieval finding the right passage.
